# ГЕО ТРИДЕШ

HTML5-игра в стиле Geometry Dash: куб, корабль, шар, НЛО, волна, порталы.

## Уровни

Лёгкие → инсейн, затем **демон**, **экстрим** и **супер демон**.

## Музыка

Оригинальные треки в стиле GD через Web Audio (не лицензионные треки Geometry Dash).

## Запуск

Открой `index.html` через локальный сервер (не `file://`).
